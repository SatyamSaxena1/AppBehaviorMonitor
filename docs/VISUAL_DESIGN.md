# Visual activity UI

The 1.1 AI review design has been retired following user feedback. Version 1.2 uses a live activity ring, two-column rule counters, category bars, per-app charts, and seven-day history. See [local rules](LOCAL_RULES.md) for semantics and refresh behavior.

Normal screens use short labels and counts. Longer coverage/retention explanations live in Settings; raw data stays in Developer Mode. Charts represent recorded activity, never a safety score. Native installed layout and accessibility still need device observation.
